# Pila Tecnológica

Este documento describe la pila tecnológica utilizada en el proyecto "Pacífico Web".

## Frontend

-   **Framework:** React 19
-   **Lenguaje:** TypeScript
-   **Bundler/Entorno:** Vite
-   **Estilos:** Tailwind CSS
-   **Routing:** React Router DOM
-   **Manejo de Estado:** Zustand

## Backend

-   **Entorno:** Node.js
-   **Framework:** Express.js

## Base de Datos y Autenticación

-   **Plataforma:** Supabase (PostgreSQL, Autenticación, Almacenamiento)

## Seguridad

-   **Tokens de Autenticación:** JSON Web Tokens (JWT)
-   **Middleware de Seguridad:** Helmet (para cabeceras HTTP seguras)
-   **Límite de Tasa:** Express-Rate-Limit (para prevenir ataques de fuerza bruta)

## Calidad de Código y Formateo

-   **Linter:** ESLint
-   **Formateador:** Prettier
